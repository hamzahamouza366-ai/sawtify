# صَوْتي 🎵 — مشغل موسيقى بأسلوب سبوتيفاي

تطبيق سطح مكتب (Electron) بواجهة داكنة تشبه سبوتيفاي، **بدون تسجيل دخول وبدون إعلانات**، بمصادر موسيقى مجانية قانونية:

- **Audius** — ملايين الأغاني المستقلة (الرائج، البحث، قوائم التشغيل، التشغيل الكامل)
- **🏛️ أرشيف الإنترنت (archive.org)** — أغانٍ ومقاطع صوتية كاملة (عربية/جزائرية/فرنسية وغيرها) + قابلة للتنزيل
- **🌍 Openverse** — موسيقى حرة برخص مفتوحة، ويضم كتالوج **Jamendo** و**Free Music Archive** و**ccMixter** — بدون أي معرّف أو تسجيل
- **🎬 YouTube** — كبحث وتشغيل احتياطي (صوت فقط، بلا فيديو)
- **🍎 Apple Music (iTunes API)** و**🎵 Deezer** — كتالوج تجاري ضخم عالمي/جزائري عبر **معاينات رسمية 30 ثانية**
- **📻 إذاعات مباشرة (Radio Browser)** — آلاف الإذاعات الحية (جزائرية، مغربية، فرنسية، عربية…)

> البحث يسأل كل المصادر في وقت واحد، ثم **يزيل التكرار** تلقائياً (يعرض الأغنية مرة واحدة، مع تفضيل المصادر الكاملة على المعاينات).

> لماذا ليس فيه «كل أغاني سبوتيفاي»؟ لأن مكتبة سبوتيفاي محمية بحقوق النشر؛ نسخها بدون إذن قرصنة. هذا التطبيق يمنحك نفس التجربة بمحتوى قانوني 100%.

## التشغيل

```powershell
cd spotify-desktop
npm start
```

أو نفّذ الملف مباشرة بعد التثبيت: `node_modules\.bin\electron .`

(التثبيت تمّ مسبقاً — إن حُذف المجلد: `npm install`)

## المزايا

- 🏠 الصفحة الرئيسية: ترحيب حسب الوقت + شرائح تصنيفات + الأكثر رواجاً + قوائم تشغيل رائجة + «استمع مجدداً»
- 🔍 بحث فوري في **7 مصادر** في وقت واحد: Audius + أرشيف الإنترنت + Openverse + YouTube + Apple Music + Deezer + إذاعات — مع **إزالة التكرار** بينها
- ❤️ أغنيات مفضلة محفوظة محلياً
- 🕘 سجل آخر ما استمعت
- ⬇️ **تنزيل للأوفلاين**: زر التنزيل بجانب أي أغنية أو في شريط المشغل — تُحفظ الملفات في `Music\Sawtify` وتُشغَّل دون اتصال (المعاينات 30ث والبث المباشر لا تُنزَّل)
- 🎨 **7 ثيمات ألوان**: أخضر سبوتيفاي، أزرق، بنفسجي، وردي، برتقالي، أحمر، تركوازي (الإعدادات ← المظهر)
- ▶️ مشغل كامل: تشغيل/إيقاف، التالي/السابق، تقدم، صوت، تكرار (قائمة/أغنية)، عشوائي
- 📋 لوحة قائمة التشغيل (Queue)
- ⌨️ اختصارات: مسافة = تشغيل/إيقاف، `/` = بحث، Shift+سهم = التالي/السابق، Esc = إغلاق
- 🔒 لا حساب، لا إعلانات، لا تتبع — كل البيانات في `localStorage` على جهازك

## بناء مثبّت Windows (.exe)

```powershell
npm run dist
```

يُنتج `release\Sawtify-Setup-1.0.0.exe` — مثبّت NSIS يُثبّت على الجهاز ويضيف اختصار سطح مكتب.
(بدون توقيع رقمي، قد يُظهر Windows شاشة SmartScreen — اضغط «مزيد من المعلومات» ← «تشغيل على أي حال».)

## اختبار سريع بدون واجهة

```powershell
npm run smoke
```

يجلب أغنية وينزّلها فعلياً إلى `Music\Sawtify` ثم يحذفها ويُعلن النتيجة.

## البنية

| الملف | الدور |
|---|---|
| `main.js` | نافذة Electron والقائمة |
| `index.html` | هيكل الواجهة |
| `styles.css` | التنسيق بأسلوب سبوتيفاي |
| `renderer.js` | البحث، التشغيل، المفضلة، الصفحات |
